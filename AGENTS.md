# AGENTS.md

## Hardware

Only the **v2** board revision is supported:

- Buttons A/B on PB0 / PB1
- SD card on SPI1 (PA9–PA12: MISO=PA9, MOSI=PA10, SCK=PA11, CS=PA12)
- Display on I2C1 (SCL=PA13, SDA=PA14)
- Sensors on PA5 (phototransistor) / PA6 (NTC thermistor)
- Build with `make build` / `pio run -e v2` (default `ENV=v2`)

On boot the bootloader mounts the SD card; if none is present it shows the
"No SD card" screen and offers the main menu.

## Documentation

The OS library documentation lives in `os/doc/html/` and is generated by
[Doxygen](https://www.doxygen.nl/) from the source files in these directories:

- `lib/PHSI245_HAL/`
- `lib/phsi245_gfx/`
- `lib/phsi245_input/`
- `lib/phsi245_storage/`

**Regenerate the docs only when the repository is tagged for a release:**

```bash
doxygen os/Doxyfile
```

The generated output under `os/doc/html/` is committed to the repository and
maintained in sync with the source only at release tags.

## Bootloader

The main firmware (`src/main.cpp`) is the OS bootloader. It provides:
- A loading animation with progress bar on startup
- SD card mounting and FAT filesystem initialization
- A file browser (UP/DOWN to navigate, A to select, B to go back)
- File info view and simulated execution (displays the file header)

The bootloader uses all four OS libraries: HAL, gfx, input, and storage.
